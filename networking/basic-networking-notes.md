# Basic Networking Notes

## Objective

Build a foundational understanding of how computers communicate across networks.

## Topics Studied

### IP Addresses
An IP address identifies a device on a network and allows network traffic to be directed to that device.

### DNS
DNS translates human-readable domain names into IP addresses.

### TCP
TCP provides reliable, ordered delivery of data between devices.

### UDP
UDP provides faster communication without establishing the same type of connection or guaranteeing delivery.

### Ports
Ports identify specific network services running on a device.

### HTTP/HTTPS
HTTP is used for web communication. HTTPS adds encryption through TLS.

## What I Learned

I learned how IP addresses, DNS, protocols, and ports work together when a computer communicates with another device or accesses a website.
